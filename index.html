FAQ

자주 묻는 질문

ScamScent가 “사기”라고 확정해 주나요?+

아니요. 자동 분석은 맥락을 완전히 이해할 수 없기 때문에 “사기 확정”이 아니라 위험 신호와 확인 포인트를 제공합니다.

입력한 문자나 URL이 서버에 저장되나요?+

이 버전은 서버 API 없이 브라우저에서 분석합니다. 최근 기록 저장을 켜면 결과 요약과 짧은 미리보기만 현재 브라우저의 LocalStorage에 저장됩니다.

조사 DB에 없는 도메인은 안전한가요?+

아닙니다. DB 부재는 안전 신호가 아닙니다. 새 도메인이나 일회성 피싱 도메인은 데이터베이스에 없을 가능성이 높습니다.

여러 사용자가 많이 검사한 사이트도 보여줄 수 있나요?+

현재 GitHub Pages 정적 버전은 사용자 간 집계 서버가 없어 전체 사용량을 공유하지 않습니다. 대신 사전 조사 DB와 각 브라우저의 최근 기록을 제공합니다. 추후 Serverless API를 연결하면 익명 집계 기능을 추가할 수 있습니다.
